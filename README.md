## 👋 Sobre el proyecto

Este repositorio contiene mi **portafolio personal**, desarrollado para presentar mi experiencia en soporte técnico, reparación de equipos y desarrollo de software, junto con mis proyectos, habilidades y formación.

Más que una página de presentación, busqué construir una experiencia con identidad propia: una estética inspirada en la tecnología, transiciones entre secciones y pequeños detalles interactivos de estilo *pixel art*.

## ✨ Características

- **Diseño adaptable** para pantallas de escritorio y dispositivos móviles.
- **Navegación por secciones** y transiciones visuales al desplazarse.
- **Presentación de proyectos, habilidades, experiencia y formación**.
- **Línea de tiempo animada** para la experiencia laboral.
- **Descarga de CV** con una animación de sello pixel art que transforma visualmente el botón en «★ OBTENIDO ★».
- **Contacto interactivo**: un destornillador pixel art golpea el enlace y abre Gmail con un mensaje preparado para que el visitante lo revise y envíe.
- **Tema visual con colores personalizados** y elementos gráficos animados.
- **Sin frameworks de interfaz**: implementado con tecnologías web nativas.

> Las animaciones son elementos visuales: la descarga del CV y la apertura de Gmail dependen del navegador y de la configuración del visitante.

## 🎮 Detalles interactivos

### 🏷️ Sello del CV

Al pulsar el botón de descarga, una mano pixel art desciende y estampa el botón. La interfaz muestra el estado **«★ OBTENIDO ★»** y comienza la descarga del archivo PDF.

### 🪛 Destornillador de contacto

Al seleccionar el enlace de correo, un destornillador pixel art cae sobre el elemento y genera un efecto visual de impacto y grietas. Después se abre la ventana de redacción de **Gmail**, con el destinatario y un mensaje inicial preparados.

Estos detalles buscan representar visualmente las dos áreas principales de mi trabajo: **software y reparación de hardware**.

Archivos CSS, JavaScript, imágenes y del CV en PDF. No incluyas contraseñas, claves de API ni información privada en el repositorio.
